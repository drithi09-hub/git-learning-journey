**06-Git-Ignore**



*touch .gitignore*



Creates a .gitignore file.



*notepad .gitignore*



Opens .gitignore for editing.



*\*.env*



Ignores all .env files.



*git status*



Checks which files Git is tracking.



**node\_modules/**



Ignores dependency folders.



**pycache/**



Ignores Python cache files.



**.vscode/**



Ignores VS Code settings.
