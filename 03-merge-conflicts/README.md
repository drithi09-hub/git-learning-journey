**03-Merge-Conflicts**



\# *git merge feature-dashboard*



Merges changes from the feature-dashboard branch into the current branch.



\# *git add dashboard.txt*



Stages the manually resolved file after fixing a merge conflict.



\# *git commit -m "Resolved dashboard merge conflict"*



Creates a commit recording the conflict resolution.



**Key Learning:**

When the same file is modified differently in two branches, Git requires manual conflict resolution before completing the merge.
