**04-GitHub-Push**



\# *git remote add origin <repository-url>*



Connects the local repository to a GitHub repository.



\# *git remote -v*



Displays the configured remote repositories for fetch and push operations.



\# *git push -u origin master*



Uploads the local master branch to GitHub and sets it as the default upstream branch.



\# *git push*



Uploads new commits to the already configured remote repository.



**Key Learning:**

Git stores history locally, while GitHub stores and shares that history remotely.
