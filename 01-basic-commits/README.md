**01-Basic-Commits**



\# *git init*



Initializes a new Git repository in the current project folder.



\# *git status*



Displays the current state of the repository, including untracked, modified, and staged files.



\# *git add .*



Stages all changes in the current directory for the next commit.



\## *git add README.md*



Stages only the specified file for the next commit.



\# *git commit -m "Initial commit"*



Creates a commit with a descriptive message and saves the current staged changes to Git history.



**Key Learning:**

Git follows a workflow of Working Directory → Staging Area → Commit.
