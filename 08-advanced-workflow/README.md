**08. Advanced Workflow Commands**



**1. Syncing Repository**



*# git fetch*



Checks for remote updates without changing local files.



*# git pull*



Downloads and applies remote updates immediately.



**2. Viewing Changes**



*# git diff*



Shows exact line-by-line file changes before committing.



**3. Temporary Work Storage**



*# git stash*



Temporarily hides unfinished changes.



\# *git stash pop*



Restores hidden changes back into working directory.



**4. Undo Staging**



*# git reset filename*



Removes file from staging area while keeping file changes.



**5. Delete Tracked Files**



\# *git rm filename*



Deletes tracked file and stages the deletion.
